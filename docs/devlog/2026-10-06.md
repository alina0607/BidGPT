## Live guessing (F1) wired into the game
- Protocol: `classify` takes an optional `"partial": true`, and the reply (including errors) echoes it. See `docs/protocol.md`.
- Game: each finished stroke sends one live guess (one request at a time; strokes drawn meanwhile go into the next one). The bottom line shows "I think it's: …". Clear drops any guess still on its way. If a live guess is in flight when "Sell it!" is pressed, the final request is queued behind it, and a partial reply is never taken as the final answer.
- Autoplay requests one live guess at frame 20 and another right before selling at frame 40 (this forces the queued path). e2e passes 5/5; `check.py` passes everything except quality, which fails only on the pre-existing `pipeline.train` with 11 parameters.
- Stroke-by-stroke test on real fixtures with the real server:
  - bicycle (6 strokes): circle → eyeglasses → **bicycle 0.54** → 0.91 → 0.97 → 0.97
  - bicycle (8 strokes): potato → baseball → basketball → flip flops ×2 → **bicycle 0.82** → 0.92 → 0.88
  - apple: pond / octagon → apple 1.00 from stroke 2

## Drawing GPT evaluation (`sketch/drawgpt_eval.py`, report `runs/drawgpt_v1/eval_report.json`)
10 drawings per class and group across all 345 classes. Every drawing goes through the game's own `classify` path: simplify, then the CNN + Transformer ensemble. "Real" means people's drawings from the validation split, used as the reference.

| | Real | Temperature 0.6 | Temperature 1.0 |
|---|---|---|---|
| top-1 / top-3 | 82.1% / 93.1% | **80.1% / 91.4%** | 59.9% / 76.8% |
| Finished (reached [end]) | 100% | 95.1% | 99.9% |
| Closer to a training drawing than real's 5th percentile | 5.0% (definition) | 10.1% | 4.7% |
| Token sequence identical to a training drawing | 0 | 3 | 1 |
| Mean pairwise distance within a class (variety) | 20.46 | 19.08 | 20.43 |

- Real scores 82.1%, matching the test set's 82.11%, so the evaluation path is right.
- All 4 identical sequences are in `line`, each 3–4 tokens: a single straight stroke. That is coincidence, not memorisation. The other 344 classes have none.
- At 0.6, 169 drawings (4.9%) never finish. After drawing the object the model keeps lifting the pen in place: the median drawing ends with 40 dots in a row until it hits the 160-token limit. Most are complex classes (hedgehog, mermaid, raccoon, dog).
- People's dot runs (strokes no wider or taller than 4 px), measured on 6,900 training drawings: median 0, 99.9% have at most 10, longest 20. This sets the rule in `drawgpt.tidy`:
  - Only drawings that never finished are changed.
  - The stroke that was cut off at the limit is removed.
  - A trailing run of more than 10 dots is removed; shorter runs may be eyes and are kept.

  On the 169 unfinished drawings it changes 115, and the median stroke count drops from 49 to 9.
